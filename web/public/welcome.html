Emergency-first

Built for the worst five minutes of someone's day.

Most systems optimise for the clerk. CLARION optimises for the person who has seconds to learn a patient's blood type, allergies and medications.

Scan to the critical facts

An emergency QR code or NFC card opens a focused view: blood type, allergies, current medications and conditions. Nothing else.

Works with the network down

The critical data can be written onto the NFC tag itself, so the mobile app reads it with no connection at all.

Break-glass, always audited

Emergency access across facilities is allowed, never silent. Every view is written to a tamper-evident audit trail.

Product tour

See what staff see.

Real screens from the running system. Fictional patients only.

One record across clinics

Conditions, medications and allergies in a single view. Entries recorded by another clinic appear as read-only, so nobody can rewrite another clinic's history.

Dangerous combinations, flagged

The interaction check reads every prescription across facilities: warfarin with aspirin, a statin with clarithromycin, and the same drug prescribed twice by different clinics.

Emergency access with a paper trail

Issue a scoped QR code or NFC card that returns only the critical fields, with no login. Every view of the record is logged, and staff can see exactly who looked.

Privacy & security

Your data stays on your hardware.

AI that never phones home

Summaries, document reading and dictation run on a local model. No third-party AI cloud is called.

Tamper-evident audit trail

Every access is chained cryptographically, so a changed or deleted entry is detectable.

PDPA-aware

Consent records, data-subject requests and retention rules are part of the system, not an afterthought.

Directory sign-in

Staff can sign in with an existing LDAP or Active Directory account; roles follow group membership.

Encrypted backups

Automated, encrypted backups with a documented restore procedure.

FHIR-ready

A read-only FHIR interface exposes core records in the standard format other systems expect.

How this demo is hosted

A small server, a secure tunnel.

This demo runs on a Raspberry Pi. There is no open port on the network; visitors reach it only through an outbound-only tunnel.
